## Use one skill in three steps

1. **Find it.** Browse the [skills by discipline](#skills-by-discipline) below. Every skill has its own page with what to attach, what you get, example prompts and a download link.
2. **Download it.** One small zip per skill, from the link on its page or in the table.
3. **Upload it.** In Copilot chat, select **Agents & Skills**, then **New agent**. Open **Configure**, expand **Skills**, select **Add**, and upload the zip. Open **Preview** and type one of the example prompts from the skill's page.

That is the whole installation. Up to eight skills fit in one agent.

## Or build a ready-made agent from a pack

A pack is a set of up to eight skills that work together on one job, with the agent's Instructions text written for you. Download the pack bundle, then follow the four steps in the pack's page: paste the instructions, upload the zips, add the suggested opening prompts (Agent Builder calls them starters), run the test prompts.

## What a skill is, in plain words

A skill is a folder with one plain text file called `SKILL.md`. The file says what the skill does, when to use it and how to do the job step by step. When you ask the agent something that matches, it reads that file and follows it. You can read the same file on GitHub before you upload anything, which is the point: every skill here is text you can check.

## What every skill here promises

- **It works with what you give it.** It reads what you attach or paste, and whatever knowledge source you have pointed your agent at. It does not reach into anything else.
- **It drafts. You decide.** Tables, drafts, questions, evidence lists. The skill files add no ability to send, save, move or delete; those actions stay with you, and the skill is written to propose them rather than take them. What an agent can actually do is set by the capabilities your tenant enables on it, not by these files.
- **It says UNKNOWN rather than guessing.** Each skill instructs the agent to mark missing information rather than fill it in. An instruction is not a guarantee, so check every output against your sources before you act on it.
- **It never signs anything off.** No approvals, no safety or legal determinations, nothing that touches permits, isolations or operations. Where a skill proposes a category or a score, it labels it a draft for you to check.
- **No code.** Just text files. Details in [SECURITY.md](SECURITY.md).
