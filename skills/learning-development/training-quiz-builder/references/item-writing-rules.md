# Item-writing rules for training-quiz-builder

Read at steps 5 to 8 of the procedure. Every rule applies to draft items. The owner may overrule any of them; the closing report records each overruled rule.

## Stems
- One question per stem, one idea; the learner can answer from the stem plus the content alone.
- A complete question, or a sentence with a single gap at or near the end. Never two gaps.
- Positive wording. Use a negative only where the content teaches a prohibition, and then capitalise NOT.
- No clues: no word that appears only in the correct option, no grammatical mismatch that rules options out.
- No trivia: slide dates, file names, page counts, unless a supplied objective names them. Presenter, author and learner names are never testable, whatever the objective says; a neutral role replaces them.
- Scenario stems describe a situation using only roles, values and steps present in the content; no invented names, sites or equipment.

## Options for multiple choice and multiple select
- Four options for single answer by default; three when the content offers only two plausible confusions; five at most.
- Exactly one correct option for single answer, per a quoted passage. Multiple select states how many to pick.
- Options parallel in grammar and length; the correct option is not the longest, the most qualified or the only one with a number.
- Distractors come from the content: an adjacent step, a neighbouring value or threshold, a similar term, the reverse of a cause and effect, a misreading the content itself warns about.
- No "all of the above", "none of the above" or "both A and B"; no humour options; no option that is partly correct.
- Where the content offers fewer confusable elements than options needed, use fewer options and note it; never invent an option.

## Type-specific rules
- True or false: only on a statement the content makes directly. The false version changes one element (value, order, actor, condition) and the explanation names that element. Avoid absolutes the content did not use.
- Short answer: model answer quoted from the content; accepted variants listed; state whether the answer is a term, a value with unit, or a step.
- Ordering: steps quoted in the content's order; the explanation cites the sequence passage.
- Matching: at least one more option than prompts, all drawn from the content; no two prompts share an answer.
- Scenario: the correct action is the one the content prescribes for that situation; the explanation quotes the rule and the triggering condition.

## Difficulty tags
- Recall: the answer is stated in one place and the item asks for it as stated. Basis: quote the single passage.
- Apply: the learner uses a stated rule, step or threshold in a described situation, and the item does not repeat the rule's wording. Basis: quote the rule and name the situation element that triggers it.
- Analyse: the learner combines two or more stated points, chooses which of several stated rules applies, or identifies the missing or wrong step in a stated sequence. Basis: quote each passage combined.
- The tag records cognitive demand. An obscure recall fact is still Recall. A long stem is not Analyse.

## Explanations
- First clause: the correct answer restated; then the passage quoted (up to 40 words) with its location (slide, page, heading or timestamp).
- One clause per distractor: what it is in the content and why it does not answer this stem, citing the passage that rules it out; otherwise "source silent".
- No teaching beyond the content, no correction of the content, no appeal to general knowledge.
- Plain tone; no praise or blame of the learner.

## Key balance
- No correct letter above 40 per cent across multiple choice items; no run of three identical letters where avoidable.
- True or false split near even, never all true or all false.
- Reordering options is the only permitted fix; content never changes to balance a key.

## Restricted words
In stems, options, model answers and explanations, these words appear only inside a quotation from the content: competent, qualified, certified, authorised, approved, safe, compliant, sufficient, passed, ready for duty. Each quotation carries its location.
