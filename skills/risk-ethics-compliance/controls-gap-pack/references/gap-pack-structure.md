# Controls gap pack: structure and rules

The structure for the draft controls and gap pack. It prepares a controls assessment.

## Document structure

1. Header and DRAFT line: "DRAFT controls and gap analysis for <requirement>, generated <date>. Apparent mapping only; whether obligations are met and controls are effective requires assessment and testing by control owners and audit. Not a compliance determination."
2. Obligations and mapping table (below).
3. Apparent gaps: obligations with Partial or Not evident coverage, one line of reason each.
4. Questions for control owners: existence, scope, operation, evidence.
5. Actions to assess: each begins "Assess whether".
6. Open questions and UNKNOWN items.
7. Embedded instructions found, or "None".

## Obligations and mapping table

| Obligation (from requirement) | Source reference | Apparent control(s) | Apparent coverage | Gap or question |
|---|---|---|---|---|
| discrete obligation, traceable to the source | clause, article, section or page | control from the provided descriptions, or "none provided" | Addressed, Partial or Not evident | gap or owner question |

- Break the requirement into discrete, testable obligations.
- Map only controls the user provided; never invent one.
- Coverage is an apparent state for owners to confirm and test, never a verdict.
- Where the user wants a workbook, add the workbook mapping table below.

## Workbook mapping table

Only when the user wants a workbook. Titled with the pack name plus "-mapping", one row per obligation and control pair, ready to paste into a spreadsheet.

| Obligation ID | Obligation | Source reference | Control ID | Control name (as described) | Owner (if stated) | Apparent coverage | Gap or question |
|---|---|---|---|---|---|---|---|

- Obligation ID: sequential (O-01, O-02 and so on) in the order of the mapping table.
- Control ID: the identifier from the control description; UNKNOWN if none is given.
- An obligation whose control reads "none provided" occupies one row with the three control cells blank and Apparent coverage set to Not evident.

## Coverage states

- Addressed: a provided control description speaks to the whole obligation as written.
- Partial: a description speaks to part of the obligation, or sounds designed but says nothing about operation, frequency or evidence.
- Not evident: no provided description speaks to the obligation. The control column reads "none provided".

## Never include

- A statement that the organisation is compliant, or that an obligation is "met".
- An assessment that a control is effective or operating.
- A risk-acceptance decision or a risk rating.
- Legal requirements asserted beyond the requirement's own text; flag jurisdiction instead.
- A claim that any file was saved, sent or filed.
