# Figure topics and gap types

Default lists for the ESG report question pack. The user may restrict the topics or add gap types; the header of the pack says which lists were used.

## Figure topics
| Topic | Disclosures usually found here |
|---|---|
| Emissions | Each scope as the report labels it, intensity figures, method basis (market-based, location-based, named protocol) |
| Energy | Consumption, renewable share, own generation |
| Water | Withdrawal, consumption, discharge, share from stressed areas |
| Waste | Generated, diverted, hazardous, recycled share |
| Land and biodiversity | Sites near protected areas, land restored, incidents |
| Workforce | Headcount, diversity ratios, turnover, training hours, pay ratios |
| Health and safety | Incident and injury rates, fatalities, hours worked, recorded as stated |
| Supply chain | Suppliers assessed, audits performed, share of spend covered |
| Governance | Board composition and independence, ethics and grievance case counts, training completion |
| Targets and progress | Baseline year and value, target year and value, current value, stated progress |

## Gap types
Use exactly one per gap row.
| Type | What is missing or does not reconcile |
|---|---|
| Metric dropped | Present in the prior report, absent now, with no explanation quoted |
| New metric without comparative | First appearance, no prior value printed |
| Incomplete figure | Value without unit, period, boundary or method reference |
| Boundary or method change without restatement | The report discloses a change but prints no restated comparatives |
| Target without baseline or current value | A target the stated figures cannot track |
| Narrative without figure | A claim of increase, decrease or achievement with no number |
| Assurance scope mismatch | The assurance statement covers fewer figures than those presented as assured, as both are stated |
| Percentage without absolutes | A share or ratio whose numerator and denominator the report does not print |
| Components do not sum | Printed parts do not add to the printed total; record the arithmetic |
| Dangling reference | A note, footnote or appendix reference that points to nothing in the material |

## Change states
Comparable (same label, unit, period length and boundary; arithmetic shown), not comparable as stated (a difference in unit, period or boundary, named in the row), not computable (prior value zero or UNKNOWN).

A gap is a question for the report owner, not a finding that the report is wrong or incomplete.
